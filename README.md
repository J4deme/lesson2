# Lesson 2 — Student Registry

Побудувати CLI-застосунок для ведення реєстру студентів та їхніх оцінок.

## Структура файлів

```
lesson2_code/
├── decorators.py   # декоратор логування
├── registry.py     # бізнес-логіка + структура даних
└── main.py         # CLI-інтерфейс
```

---


---

### `decorators.py`: Декоратор логування

Напиши декоратор `log_action` за допомогою `functools.wraps`.

Він має виводити перед виконанням функції:
```
  [LOG] назва_функції() →
```
і повертати результат без змін.

---

### `registry.py`: Структура даних

Оголоси приватну змінну модуля:
```python
registry: dict[str, list[int]] = {}
```
Формат: `{ "Anna": [95, 87, 92], "Bob": [70, 65] }`

---

### `registry.py`: `add_student(name)`

- додай студента з порожнім списком оцінок
- Поверни рядок: `"Студента '{name}' додано."`
- Постав декоратор `@log_action`

---

### `registry.py`: `add_grade(name, grade)`


- Інакше → додай оцінку до списку студента
- Поверни рядок: `"{name}: оцінка {grade} збережена."`
- Постав декоратор `@log_action`

---

### `registry.py`: `get_average(name) -> float`

- Якщо список оцінок порожній → поверни `0.0`
- Інакше → поверни середнє арифметичне
- Постав декоратор `@log_action`

---

### `registry.py`: `get_top_students(threshold=80.0) -> list[tuple[str, float]]`


1. Порахуй середнє для кожного студента (тільки тих, у кого є оцінки) 
2. Відфільтруй тих, чиє середнє `>= threshold`, та округли до 1 знак
3. Посортуй за спаданням середнього

Також реалізуй `get_all_students() -> dict[str, list[int]]` — повертає копію `_registry`.

Постав `@log_action` на `get_top_students`.

###  `main.py`: CLI-інтерфейс

Реалізуй меню вибору дії через `input()`:

```
╔══════════════════════════════╗
║      Student Registry        ║
╠══════════════════════════════╣
║  1. Додати студента          ║
║  2. Додати оцінку            ║
║  3. Середня оцінка           ║
║  4. Топ студентів            ║
║  5. Всі студенти             ║
║  0. Вийти                    ║
╚══════════════════════════════╝
```

Вимоги:
- Кожна дія — окрема функція (`handle_*`)
- Словник `ACTIONS: dict[str, callable]` для диспетчеризації
- У головному циклі `try/except` перехоплює помилки
- Запуск тільки через `if __name__ == "__main__": main()`

---

## Запуск

```bash
python main.py
```
